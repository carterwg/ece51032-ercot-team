# System generation reserve-margin study

## Method and interpretation

For each period, system load is the sum of all bus demands in `demand_bus.csv`. Total available active generation capacity is the sum of `p_max_mw` for generators whose `status` is `1` in `generator_limits.csv`; inactive units are excluded. The requested reserve margin is calculated as:

```text
reserve margin (MW) = total active generator Pmax (MW) - system load (MW)
```

This is arithmetic nameplate headroom, not a percent reserve margin or an operational-reserve assessment. It does not account for transmission deliverability, generator ramping/availability, outages, or other operating constraints. Period indices are zero-based.

## Relationship to the hosting-capacity ceiling

Yes. In period 109, the remaining aggregate generation headroom is **3,024.604059 MW**. The highest value in the all-bus minimum-hosting-capacity results is **3,024.604059 MW** (bus 6349); the difference is only **0.000000008 MW**, attributable to numerical precision. The approximately 3,024.6 MW hosting-capacity ceiling therefore corresponds to the remaining generation headroom in the peak-load period.

This is consistent with the earlier single-bus hosting-capacity result: at the binding period, the system cannot serve any additional load once all available active generation has reached Pmax. The matching aggregate headroom explains the ceiling in this experiment, but it does not mean every bus can host that amount. Network constraints can impose lower, bus-specific hosting capacities; a reserve-margin calculation alone does not establish that generation can be delivered to a particular bus.
